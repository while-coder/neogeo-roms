# neogeo screenshots

Game screenshots referenced by the root catalog.json. Filenames are stable hashes of the original source URLs; duplicate URLs share one file.

- manifest.json maps ROM SHA-256 hashes and game names to local files, original source URLs, public screenshot URLs, and image SHA-256 hashes. It also lists games still missing a screenshot.
- matches.json, when present, records the evidence used to match additional screenshots.
- Original image URLs and their respective providers are retained in manifest.json. Images remain the property of their respective rights holders.

Resources used for matching:

- https://github.com/libretro-thumbnails/libretro-thumbnails
- https://github.com/libretro/libretro-database
- https://github.com/yingw/rom-name-cn
