# neogeo-roms

Game catalog and ROM archives used by GameEmulator (neogeo).

- Catalog: https://raw.githubusercontent.com/while-coder/neogeo-roms/main/catalog.json
- `roms/`: archives referenced by `games` and `dependency_files`.
- `rom_url_base` resolves the relative `download_url` values in the catalog.
- File sizes and SHA-256 hashes are recorded in `catalog.json`.

中文名称来源与使用要求见 [ROM-NAME-CN-NOTICE.md](ROM-NAME-CN-NOTICE.md)。
游戏资源与 BIOS 的版权属于各自权利人；本仓库不授予额外使用或再分发权。
